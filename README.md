# 知白守黑 · Agent Skills 合集

十个可以直接装进 AI Agent 的技能，覆盖**投标技术文档**、**求职面试**、**家庭防骗**、**技能供应链安全**、**技能开发方法论**五条线。
每个技能都是一份 `SKILL.md` 加配套的深度知识库，不是提示词片段——有输入、有流程、有判定规则、有输出模板、有反模式。

根目录的 `SKILL.md` 是**合集索引**：装它之后，Agent 会先判断你的需求属于哪一类，再自动去读对应子技能的工作流，不需要你记每个技能叫什么。只要一个能力时，也可以直接复制那个子目录。

适用于 Claude Code、Codex、Cursor、WorkBuddy、DeepSeek Harness 等任何支持 Agent Skills 的客户端。

---

## 为什么做这十个

选题来自对 SkillHub 平台 **22,312 个插件**和数万条技能搜索数据的实测分析，不是拍脑袋：

- 投标「参数响应表」全站只有 2 个竞品，头部 498 下载；「测试大纲」只有 1 个，头部 27 下载——需求被验证过（技术标大盘 38,475），但没人愿意做细。
- 「防骗」相关头部做到 200 万级下载，但三个头部产品全部只做话术识别，没有技术检测维度，也没有子女视角和单位宣传视角。
- 「简历诊断」赛道头部仅 3,180 下载，人群极大而供给极弱。

我们选的是**需求真实、供给稀薄、自己又有专业积累**的位置，而不是往最卷的赛道里再挤一个。

后续新增的投标技术方案、Skill 开发上架工厂、模拟面试追问教练沿用同一套方法：先做关键词实测与竞品核对，再选供给薄弱、能和已有技能串成工作流的切口。

每个技能都含：

- `README.md` — 一分钟上手
- `FAQ.md` — 高频问题
- `TROUBLESHOOTING.md` — 异常输入怎么处理
- `references/` — 深度知识库（18 类骗局详解、七类设备测试项库、20 岗位改写库等）

## 安装

### Claude Code / Codex / Cursor / WorkBuddy

把本仓库的技能目录复制进对应客户端的技能目录即可，例如：

```bash
git clone https://github.com/odin1024/zhibai-skills.git
cp -r zhibai-skills/skills/fangpian-canmou ~/.claude/skills/
```

也可以只复制单个技能的 `SKILL.md` + `references/`，技能本身不依赖运行时代码。

若想让 Agent 自己判断该用哪个技能，把根目录的 `SKILL.md` 连同整个 `skills/` 目录一起放进技能目录即可；这份索引会按意图路由到对应子技能，不会在索引层凭空作答。

### DeepSeek Harness

仓库打了 `dsh-plugin` topic，可在 SkillHub 插件页或 DSH 插件市场里搜索安装；也可以直接把安装提示词发给 Agent：

```
请安装 DSH 插件 odin1024/zhibai-skills 中的 fangpian-canmou 技能。
```

## 几点设计原则

1. **不做代写，做判断。** 参数响应表不许把「待确认」改成「无偏离」；简历医生不虚构经历；防骗参谋不替用户下「一定是骗子」的绝对结论。
2. **判定必须可复核。** 偏离状态只给四种：无偏离 / 正偏离 / 负偏离 / 待确认，禁止「基本满足」；测试项必须写全六要素，尤其是量化判定准则。
3. **写清不能做什么。** 每个技能都单列能力边界和一条底线，避免过度承诺。
4. **事实准确性优先。** 涉及路径、电话、时限、标准的表述逐条核对；拿不准的宁可写成「越早越好」，也不编造一个「10 分钟黄金窗口」。
5. **反模式比正例更重要。** 每条反模式都写清「为什么错 + 正确做法」。

发布前统一按 38 项质量检查清单验收（事实准确性、逻辑一致性、完整性、丰富度、可用性、搜索分发、安全合规七组）。
