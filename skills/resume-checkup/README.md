# 简历医生

不帮你写简历，帮你诊断简历。三分钟知道简历死在哪一关。

## 一分钟演示

**输入**

```
简历：（正文）
目标岗位：某电商公司 用户增长运营（3-5 年）
```

**输出（节选）**

```
总分：19/30

| 维度 | 得分 | 一句话判断 |
| 岗位匹配度 | 3/5 | 增长经验有，但缺少「留存」和「私域」两条核心线 |
| 成果量化   | 3/5 | 有一半条目还是职责描述 |
| 结构清晰度 | 4/5 | 模块齐全，但核心成果被埋在第二页 |
| 信息密度   | 2/5 | 「负责」「参与」「协助」出现 11 次 |
| ATS 友好度 | 5/5 | 纯文本，无表格 |
| 可信度     | 2/5 | 「增长 300%」无基数，面试必被追问 |

致命问题：
1. 三条核心经历全用「参与」，看不到你的决策权
2. 「用户增长 300%」没有基数和周期，像包装
```

**逐条改写**

> 原文：负责公司产品的日常运营工作，参与活动策划，协助团队完成业绩目标。
>
> 改后：独立运营 3 个微信社群（合计 8000 人），策划 12 场裂变活动，单场最高拉新 1200 人，带动季度复购率从 18% 提升到 27%。

## 它解决什么

| 痛点 | 现在 |
|---|---|
| 投了几十家没回音，不知道问题在哪 | 六维评分，定位到具体哪一维拖后腿 |
| 知道要改，不知道从哪改 | 逐条给「原文 → 问题 → 改后 → 理由」 |
| 不知道 JD 里的词要不要都塞进去 | 关键词分必备/加分/行业，标出缺口和同义替换 |
| 面试总被问住 | 提前给「面试官看到这份简历会追问什么」 |
| 网上模板千篇一律 | 按应届/骨干/转行/管理/35+ 五类人群给不同策略 |

## 怎么用

1. 贴简历全文
2. 贴目标岗位 JD（这一步决定诊断质量）
3. 补三句背景：几年经验、什么岗位、想去什么公司

## 输出物

- 六维评分卡（总分 30）
- 致命问题清单
- 逐条改写对比
- ATS 关键词缺口表
- 面试官预判问题
- 下一步行动清单

## 适用与不适用

**适用**：应届生、跳槽、转行、管理岗、35+ 求职者的简历诊断。

**不适用**：代写经历、虚构职级年限、承诺面试结果、海外英文简历的 ATS 适配。

## 说明

- 评分标准来自招聘实务中的通用判断，不是任何一家公司的官方标准
- 诊断只针对「表达效率」，不评价你的能力高低
- 简历内容只在你本地处理，不上传任何外部服务
