# 异常处理

## 输入类问题

| 情况 | 处理 |
|---|---|
| 只说「要反诈材料」 | 追问：什么场景、给谁看、多长时间、要不要台账 |
| 受众不明确 | 按员工/老人/学生三类各给一版开场，让用户选 |
| 时长没定 | 默认给 10 分钟版，同时说明可扩展 |
| 要求「越全越好」 | 劝减：一次讲三个骗局是上限，多了记不住 |
| 多场景混在一起 | 拆成多个素材，不合并 |

## 内容类问题

| 情况 | 处理 |
|---|---|
| 用户要求加数据但没来源 | 拒绝编造，给「场景替代」方案 |
| 用户要求「讲得吓人一点」 | 改为「真实案例 + 具体金额 + 转折点细节」，不用恐吓词 |
| 要求用受害者真名/照片 | 提示需授权，建议打码或化名 |
| 要求评论具体未公开案件 | 拒绝，只做通用拆解 |
| 案例太旧（三年前） | 提示骗局半年迭代，建议换近一年类型 |

## 场景适配

| 情况 | 处理 |
|---|---|
| 听众是老人 | 去术语、放大字号、加实物演示、结尾发卡片 |
| 听众是财务 | 重点讲冒充老板、假合同、对公账户 |
| 听众是学生 | 用游戏/兼职/追星/校园贷切入，允许调侃语气 |
| 听众是混合人群 | 按多数人定调，个别场景补一句 |
| 现场没有投影 | 改成「两块展板 + 现场演练」方案 |

## 效果与台账

| 情况 | 处理 |
|---|---|
| 领导要台账 | 给三件套：签到表、测试成绩、现场照片 |
| 要写活动总结 | 给「数据 + 动作 + 反馈」三段式，不用空话 |
| 要评估效果 | 给三个可量化指标，不用「发放份数」 |
| 要报上级材料 | 提示数据须可溯源，标注来源 |

## 拒绝执行

1. **要求编造数据、案例、受害者原话**——宣传事故风险
2. **要求使用未授权受害者影像**——侵权
3. **要求写官方通报口径**——超出范围
4. **要求承诺「讲完零发案」**——不专业且无法兑现
5. **要求提供诈骗实施细节用于「演示」**——不提供可被滥用的内容
