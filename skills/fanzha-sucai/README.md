# 反诈素材库

给要做反诈宣传的人：宣讲稿、短视频脚本、案例拆解、测试题、展板文案。每条素材配一个可执行动作。

## 一分钟演示

**输入**

```
场景：社区反诈宣传周，活动室，60 位老人，15 分钟
要求：不用 PPT，能互动，结尾要留个东西
```

**输出（节选）**

```
开场（1 分钟）
「今天不讲大道理。就说一件事：如果明天有人打电话说你涉嫌洗钱，
 你能不能在 30 秒内判断出他是骗子。」
（停 3 秒，看反应）

三个骗局，每个 80 秒
1. 冒充公检法 → 挂断，自己拨 110
2. 养老项目   → 不签字，先查民政备案
3. 网上认识的人带你赚钱 → 一分不投，先试提现

互动（3 分钟）
请一位阿姨上台，我演骗子，她演自己。
演完问全场：「刚才哪句话最像真的？」

结尾（2 分钟）
发卡片：印 96110 + 子女电话，让贴冰箱上
一句话：「转账之前，先给一个人打电话。」
```

## 它解决什么

| 痛点 | 现在 |
|---|---|
| 不知道讲什么，只能念案例 | 按「剧本-转折-动作-记忆点」四段式组装 |
| 讲完没人记住 | 每段强制配一个动作 |
| 数据不敢用，怕被追责 | 明确三条红线：可溯源、不羞辱、不空谈 |
| 不同人群讲法一样 | 四类受众分别给开场钩子 |
| 领导要台账 | 给签到 + 测试 + 照片三件套 |

## 覆盖素材

- 宣讲稿：10 / 20 / 30 分钟三档，带时间分配
- 短视频脚本：60 秒 6 镜，含口播词与画面
- 案例拆解卡：展板、PPT 通用
- 互动测试：10 题，带答案与讲解
- 展板文案：标题 + 3 条要点 + 一句话行动

## 适用与不适用

**适用**：企业培训、社区活动、学校讲座、银行网点、宣传月台账。

**不适用**：编造案例数据、替代公安官方口径、视频拍摄剪辑、案件法律定性。

## 三条红线

1. **数据可溯源**：所有比例金额必须来自公开通报，查不到就删
2. **不羞辱受害者**：不用「贪婪」「活该」
3. **不只讲不练**：每段至少一个动作
