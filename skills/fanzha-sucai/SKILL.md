## 一分钟看懂

```
输入：场景（宣讲/短视频/展板/测试）+ 受众（员工/老人/学生/财务）+ 时长
  ↓
输出：
  ① 宣讲稿（10 / 20 / 30 分钟三档，带时间分配）
  ② 短视频脚本（60 秒 6 镜，含口播词与画面）
  ③ 案例拆解模板（骗局怎么走、你该怎么做）
  ④ 互动测试（10 题，带答案与讲解）
  ⑤ 展板文案（标题 + 3 条要点 + 一句话行动）
```

三条硬原则：**每个案例配一个动作、所有数据可溯源、不羞辱受害者。**

## 什么时候用

| 场景 | 你会怎么说 |
|---|---|
| 单位要做反诈培训 | 「给 200 个员工讲半小时防骗，写个稿」 |
| 社区反诈宣传周 | 「社区搞活动，要展板和讲解」 |
| 学校开学第一课 | 「给大一新生讲反诈，要能听进去」 |
| 银行网点宣传 | 「客户等待区放个短视频」 |
| 安全生产月/宣传月 | 「上级要求做反诈材料，要有台账」 |

## 什么时候不该用

- **要真实案例的独家细节**→ 只能引用公开通报，本技能不编案例
- **要具体案件的法律定性**→ 由司法机关认定
- **要制作视频成片**→ 本技能出脚本，拍摄剪辑需另行处理
- **要替代公安官方宣传口径**→ 官方材料优先，本技能只做补充

## 三步上手

**第一步**：说场景和受众——在哪讲、讲给谁、多长时间

**第二步**：说约束——有没有指定主题、要不要留台账、能不能放视频

**第三步**：说要哪种输出——宣讲稿 / 脚本 / 测试题 / 展板

## 核心工作流

### 第一步：定场景与时长

| 场景 | 推荐时长 | 素材重心 |
|---|---|---|
| 企业入职培训 | 20 分钟 | 职场高发（冒充领导、刷单、网贷） |
| 社区活动 | 10—15 分钟 | 老人高发（养老、保健品、冒充公检法） |
| 学校讲座 | 30 分钟 | 学生高发（游戏、兼职、校园贷、追星） |
| 银行网点 | 60 秒循环 | 转账前最后一问 |
| 财务人员专场 | 30 分钟 | 冒充老板、假合同、对公账户 |

### 第二步：定受众与话术

同一个骗局，对不同人讲法完全不同：

| 受众 | 他们最在意 | 开场怎么抓 |
|---|---|---|
| 企业员工 | 别丢工作、别背锅 | 「财务转错一笔，可能赔上一年工资」 |
| 社区老人 | 别给子女添麻烦 | 「不是怕你被骗，是怕你不好意思跟孩子说」 |
| 大学生 | 别丢面子、别被同学笑 | 「被骗的人里，一半是觉得自己不会上当的」 |
| 财务人员 | 职业责任、合规 | 「老板的微信，也可能是假的」 |

### 第三步：组装素材

按「一个骗局 = 一段剧本 + 一个动作 + 一句记忆点」的结构写，不要堆案例。

**结构公式**

```
① 场景还原（30 秒）：让听众代入「这事会发生在我身上」
② 关键转折（20 秒）：哪一个瞬间其实已经不对了
③ 正确动作（20 秒）：只需要记住一个动作
④ 记忆点（10 秒）：一句话，能复述给别人
```

### 第四步：校对三条红线

出稿前必查：

1. **数据是否可溯源**：所有比例、金额、案件数，必须来自公安部、国家反诈中心、本地公安公开通报。查不到就删掉，不要用「据统计」糊弄。
2. **是否羞辱受害者**：不用「贪婪」「愚蠢」「活该」。受害不是道德问题。
3. **是否只讲不练**：每段至少一个可执行动作，否则删掉。

## 素材模板

### 模板 A：10 分钟宣讲稿

```markdown
# 10 分钟反诈宣讲（社区版）

## 0—1 分钟｜开场：不吓人，先共情
「今天不讲大道理。就说一件事：如果明天有人打电话说你涉嫌洗钱，
你能不能在 30 秒内判断出他是骗子。」
（停顿 3 秒，看反应）

## 1—5 分钟｜三个高发骗局，每个 80 秒
### 骗局 1：冒充公检法
- 剧本：电话 → 涉嫌洗钱 → 安全账户 → 不许告诉家人
- 转折点：真警察不会电话办案，没有「安全账户」
- 动作：挂断，自己拨 110

### 骗局 2：养老项目
- 剧本：免费旅游 → 高息养老床位 → 催签合同
- 转折点：催你当场决定的，都不怕你回去想三天
- 动作：不签字，先查民政备案

### 骗局 3：假亲情/杀猪盘
- 剧本：加好友 → 天天问候 → 带你投资
- 转折点：没见过面的人，不会真的关心你发财
- 动作：一分钱不投，先试提现

## 5—8 分钟｜现场演练（关键环节）
请一位听众上台，你演骗子，他演自己。
演完问全场：「刚才哪句话最像真的？」
（这个环节比讲十遍案例有效）

## 8—10 分钟｜三个动作 + 一句话
1. 手机装国家反诈中心，开来电预警
2. 单日转账限额调到 5000 以下
3. 96110 存进通讯录，标「一定要接」
一句话：「转账之前，先给一个人打电话。谁都可以，就是别自己决定。」
```

### 模板 B：60 秒短视频脚本（6 镜）

| 镜号 | 时长 | 画面 | 口播 |
|---|---|---|---|
| 1 | 0—8s | 手机特写，来电显示「公安局」 | 「这个电话，差点让我妈转走 8 万。」 |
| 2 | 8—18s | 老人紧张接电话 | 「他说我涉嫌洗钱，要转到安全账户自证清白。」 |
| 3 | 18—28s | 字幕打出三个关键词 | 「记住三个字：安全账户——不存在。」 |
| 4 | 28—38s | 子女拿过手机挂断 | 「真警察不会电话办案，更不会让你转钱。」 |
| 5 | 38—50s | 拨 110，镜头给号码 | 「挂断，自己拨 110。别用他给的号。」 |
| 6 | 50—60s | 全家坐一起 | 「转账前，先给一个人打电话。」 |

### 模板 C：案例拆解卡（展板/PPT 通用）

```
【骗局名称】冒充公检法
【一句话】说你涉案，要你转钱自证清白
【他怎么走】
  1. 来电显示官方号码（改号）
  2. 报出你的身份信息（信息已泄露）
  3. 恐吓 + 不许告诉家人（切断求助）
  4. 转到「安全账户」（钱一去不回）
【哪一步不对】第 3 步。任何让你「别告诉家人」的，都是骗子。
【你该做】挂断 → 自己拨 110 → 告诉家人
【记住这句】公检法不会电话办案，没有安全账户。
```

### 模板 D：10 题互动测试

```markdown
1. 警察打电话说你涉嫌洗钱，要你把钱转到安全账户，你应该：
   A. 配合转账  B. 挂断并自己拨 110  C. 先转一半试试
   答案：B｜讲解：公检法不电话办案，没有安全账户。

2. 网恋对象说他有内部消息，带你投资稳赚，你应该：
   A. 小额试试  B. 一分不投，先试提现  C. 见面再说
   答案：B｜讲解：前期小额提现是剧本，加大投入才开始收割。

3. 有人让你用银行卡帮他收钱再转出，给你 5% 手续费：
   A. 帮个忙  B. 拒绝，这是跑分洗钱  C. 只帮一次
   答案：B｜讲解：你的卡会涉案冻结，可能承担法律责任。

（依此类推，每题必须带讲解，不能只给答案）
```

## 三个真实样例

### 样例 1：企业员工 20 分钟

**输入**：200 人制造企业，安全生产月，要求留台账

**输出要点**
- 主题定为「你的一个转账，可能是公司的一年利润」——财务视角切入，全员都能听懂
- 三个骗局：冒充老板（财务）、刷单兼职（一线员工）、网贷（年轻员工）
- 现场演练：请财务上台，演「老板微信让你紧急打款」
- 台账：签到表 + 测试题成绩 + 现场照片，三样齐了就能交差

### 样例 2：社区老人 15 分钟

**输入**：社区活动室，60 位老人，平均 70 岁

**输出要点**
- 全程不用 PPT，用两张放大的展板
- 不讲「杀猪盘」这种词，讲「网上认识的人带你赚钱」
- 重点讲「三不」：不转账、不给验证码、不共享屏幕
- 结尾发一张卡片：上面印 96110 和子女电话，让老人贴冰箱上

### 样例 3：大学新生 30 分钟

**输入**：大一新生 300 人，开学第一课

**输出要点**
- 开场用「你们中间有 3 个人今年会被骗」——用真数据，注明来源
- 讲四个：游戏账号交易、兼职刷单、校园贷、追星应援
- 互动：现场扫码做 10 题测试，大屏实时排名
- 结尾给「三句话」：不垫钱、不扫码、不裸聊

## 反模式

| 做法 | 为什么无效 |
|---|---|
| 全程念案例，不给动作 | 听完只记得「有人被骗了」，不知道怎么防 |
| 用「据统计」但不给来源 | 听众不信，还可能被上级追责 |
| 「不装 App 就是对自己不负责」 | 恐吓式宣传，逆反心理强 |
| 说受害者「贪心」「活该」 | 现场有受害者，从此不会再开口 |
| 案例全是三年前的 | 骗局半年一迭代，老案例没共鸣 |
| 只讲老人和学生，不讲自己 | 听众觉得「跟我没关系」 |
| 讲 20 个骗局 | 记不住，等于没讲 |
| 没有互动 | 单向输出，留存率极低 |
| 用专业术语（跑分、杀猪盘） | 老人听不懂，员工记不住 |

## 常见问题

**Q：没有真实数据，能不能编一个？**
不能。反诈宣传编数据，一旦被追问来源就是事故。没有数据就用场景代替——「上个月隔壁小区有位阿姨……」这种也不能编，除非确实发生过。

**Q：领导要求「讲得震撼一点」，怎么办？**
震撼不等于恐吓。有效做法是「真实案例 + 具体金额 + 受害者原话」，比形容词有力。如果非要加情绪，加在「转折点」上——「他当时已经输完密码了，就差按确认」。

**Q：老人听不懂「杀猪盘」怎么办？**
换成「网上认识的人，聊出感情了，带你投资」。所有术语都要翻译成生活语言，这是硬要求。

**Q：怎么证明宣传有效果？**
三个可量化指标：测试题平均分、现场举手率（问「遇到过类似情况的举手」）、后续咨询量。不要用「发放材料 X 份」这种假指标。

**Q：能不能直接用公安的官方材料？**
可以，而且优先用。官方材料口径准、有权威性。本技能的价值是帮你把官方材料改写成「适合你这个场景和人群」的版本。

**Q：短视频没人看怎么办？**
前 3 秒决定生死。开头不要「大家好，今天讲反诈」，要直接抛冲突：「我妈刚才差点转出去 8 万。」

## 错误处理

| 情况 | 处理 |
|---|---|
| 只说要「反诈材料」 | 追问三件事：什么场景、给谁看、多长时间 |
| 受众不明确 | 按最常见的三类（员工/老人/学生）分别给一版 |
| 要求「必须提到某个官方平台」 | 按需植入，但不夸大功能 |
| 要求编造数据或案例 | 拒绝，并给替代方案（用场景代替数据） |
| 要求「保证宣传后没人被骗」 | 说明宣传只能降低概率，无法杜绝 |
| 涉及具体案件 | 只做通用拆解，不评论未公开案件 |

## 稳定性与一致性

- 同一场景同一时长，输出结构稳定（开场-案例-演练-动作）
- 案例库固定为公开通报的通用类型，不虚构细节
- 不联网，不引用实时数据
- 字数与时长匹配：中文口播约每分钟 200—240 字（正式宣讲可到 250，短视频建议 220 以内）

## 能力边界

**能做**：宣讲稿、短视频脚本、案例拆解、测试题、展板文案、宣传方案框架。

**不能做**：
- 不编造数据、案例、受害者原话
- 不替代公安官方口径
- 不做视频拍摄剪辑
- 不评估具体案件、不下法律结论

**一条底线**：反诈宣传的目标不是让人「害怕」，是让人在那一刻「有一个动作可以做」。每条素材都必须能回答：听众明天遇到时，会做什么？
