# 参数响应表生成器

把招标文件的技术参数，逐条转成可交付的参数响应表。投标文件里最容易失分的一章，交给它。

## 一分钟演示

**输入**

```
3.1.1 ★ 整机吞吐量 ≥ 10Gbps，须提供第三方检测报告
3.1.2 并发连接数 ≥ 200 万
3.1.3 ▲ 支持 IPS 特征库自动更新
3.1.4 ★ 提供原厂授权函

我们投 XX 品牌 XX 型号，彩页和检测报告在附件。
```

**输出**

| 序号 | 招标技术参数要求 | 投标响应 | 偏离情况 | 证明材料 | 页码 |
|---|---|---|---|---|---|
| 3.1.1 ★ | 整机吞吐量 ≥ 10Gbps | 吞吐 12Gbps（@1518B，RFC2544 双向） | 正偏离 | 第三方检测报告（CNAS） | P56 |
| 3.1.2 | 并发连接数 ≥ 200 万 | 并发连接 200 万 | 无偏离 | 产品彩页 | P12 |
| 3.1.3 ▲ | 支持 IPS 特征库自动更新 | 支持，每日自动更新，可离线导入 | 无偏离 | 官网功能说明 | P18 |
| 3.1.4 ★ | 提供原厂授权函 | 已提供 | 无偏离 | 原厂授权函 | P102 |

```
★条款合计：2 条　已响应：2 条　负偏离：0 条　待确认：0 条
风险提示：3.1.2 恰好卡线，若实测值低于标称值将构成负偏离，建议补检测报告。
```

## 它解决什么

| 痛点 | 以前怎么做 | 现在 |
|---|---|---|
| 200 条参数人工对照，一做一整天 | 逐条复制粘贴，容易漏 | 批量拆解，按章节分批 |
| ★条款混在普通条款里，漏一条就废标 | 靠经验挑，靠人复核 | 自动标记 + 出表后强制自查 |
| 偏离判定凭感觉，「基本满足」写一堆 | 评审现场被质疑 | 四种结论强制四选一 |
| 证明材料翻不到 | 页码空着 | 生成证明材料索引表 |
| 负偏离不知道怎么解释 | 硬着头皮写「满足」 | 给三条补救路径 + 明确不建议的做法 |

## 怎么用

1. 把招标文件参数部分贴进来（扫描件先 OCR）
2. 补一句：什么类型项目、投什么产品、有没有产品资料
3. 说要哪种输出：Word 表格 / Excel 可粘贴 / 先看风险清单

## 输出物

- **参数响应表**：六列标准格式，可直接贴进标书
- **★▲条款清单**：单独列出实质性条款，防止漏项
- **风险清单**：负偏离、待确认、废标风险，逐条给建议动作
- **证明材料索引**：哪份材料覆盖哪几条参数、在第几页

## 适用与不适用

**适用**：货物类、服务类、系统集成类的政府采购与企业采购；技术规格书、参数应答、技术偏离表。

**不适用**：写技术方案正文、报价、评分测算、法律层面的质疑投诉。

## 数据与依据

- 判定规则参考《中华人民共和国招标投标法》《政府采购法》及其实施条例的通用实务做法
- ★/▲ 条款的具体效力**以招标文件「评标办法」章节为准**，本技能只做识别与提示，不做法律认定
- 不联网、不调用外部接口，所有判断基于你提供的文本
