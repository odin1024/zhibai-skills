## 一分钟看懂

不是给老人看的，是给子女用的。

```
输入：父母的年龄、住哪、性格、有没有被骗过
  ↓
① 易感类型 —— 孤独型 / 贪利型 / 权威恐惧型 / 热心型
② 手机防线 —— 九项设置，具体到点哪里
③ 演练脚本 —— 五个场景，陪父母练一遍
④ 出事后怎么办 —— 三步骤 + 不吵架的话术
```

核心不是「讲道理」，是**把防线装在他手机上，把反应练成肌肉记忆**。

---

## 什么时候用

| 场景 | 你会怎么说 |
|---|---|
| 发现父母在跟可疑的人聊 | 「我妈最近总跟一个炒股的老师聊天」 |
| 父母转发可疑链接/群 | 「我爸天天在群里抢红包做任务」 |
| 想提前做防护 | 「我爸妈自己住，想给他们手机设一下」 |
| 已经被骗过一次 | 「上次被骗了 2 万，怕还有下次」 |
| 社区/银行要做老年宣传 | 「给社区老人讲防骗，怎么讲才有用」 |

## 什么时候不该用

- **正在被骗、钱要转出去**→ 直接打 110，不要先看分析
- **要追回资金**→ 只有报警，本技能不承诺追款
- **要判断某个养老机构是否合法**→ 查民政部门备案，本技能只做风险提示
- **父母已经严重认知障碍**→ 需要监护和法律安排，超出本技能范围

## 三步上手

**第一步**：说清父母情况——多大年纪、自己住还是跟子女住、性格偏哪类、有没有被骗过

**第二步**：说你的目标——想提前防、已经发现苗头、还是出事后处理

**第三步**：说要哪种输出——手机设置清单 / 演练脚本 / 沟通话术

## 核心工作流

### 第一步：判断易感类型

老人被骗不是因为「笨」，是因为某一种需求正好被击中。四类画像，对策完全不同：

| 类型 | 特征 | 容易被什么骗 | 对策重点 |
|---|---|---|---|
| 孤独型 | 子女不在身边，爱聊天，渴望被关心 | 假亲情、杀猪盘、冒充干儿子干女儿 | 补陪伴 + 识别「无条件对你好」的人 |
| 贪利型 | 退休金想增值，爱打听理财 | 虚假投资、养老项目、高息理财 | 用真实收益对比，不讲道德 |
| 权威恐惧型 | 怕惹事、怕涉案、听干部的话 | 冒充公检法、冒充医保社保 | 建立「先打给我」的硬规则 |
| 热心型 | 爱帮忙、爱转发、怕给人添麻烦 | 刷单跑分、代收款、帮忙转账 | 讲清「帮人可能犯法」的后果 |

多数老人是混合型，但总有一类是主导。判断方法：看他平时最在意什么、最怕什么。

> 十个生活场景的对应打法（广场舞认识的朋友、免费体检、低价旅游、微信群、上门推销等），见 `references/老人易感场景.md`。

### 第二步：装手机防线

九项设置，按重要性排序。给父母设置时，一项一项做，边做边解释「这是防什么的」。

| # | 设置 | 怎么做 | 防什么 |
|---|---|---|---|
| 1 | 关闭未知来源安装 | 设置 → 安全 → 关闭「允许安装未知应用」 | 木马 App |
| 2 | 开启骚扰拦截 | 电话 → 设置 → 骚扰拦截 → 开启 | 诈骗电话 |
| 3 | 96110 加白名单 | 联系人里存 96110，备注「反诈专线，一定要接」 | 漏接预警 |
| 4 | 装国家反诈中心 App | 应用商店搜，开启来电预警 | 诈骗号码 |
| 5 | 关闭小额免密 | 支付设置 → 关闭免密支付 | 盗刷 |
| 6 | 调低单日转账限额 | 银行 App → 转账设置 → 单日限额调至 5000 以下 | 大额损失 |
| 7 | 微信关闭「手机号搜到我」 | 微信 → 设置 → 朋友权限 → 添加我的方式 → 关闭「手机号」 | 陌生人添加 |
| 8 | 微信开启「加我需验证」 | 朋友权限 → 开启验证 | 陌生人冒充熟人 |
| 9 | 设置紧急联系人 | 手机 SOS / 紧急呼叫里加子女号码 | 出事能求助 |

**做完这九项，能挡掉大部分低级骗局。** 高级的（已经聊上的）要靠演练。

### 第三步：陪父母演练

不是讲道理，是「演一遍」。五个人高频场景，每个都按「骗子怎么说 → 正确反应 → 练什么」走。

**演练方法**：你演骗子，让父母演自己。演完问一句「刚才哪句话让你差点信了」。别评判，只复盘。

#### 脚本 1：冒充子女同事

```
骗子：阿姨，我是小王的同事，他出车祸了，现在在医院，急需 3 万押金，
      他手机摔坏了，让我用我号码打给您。
正确反应：挂断，用自己存的儿子号码打回去。
         打不通就打给儿媳/单位/其他家人。
训练点：任何「别人替子女传话要钱」的情况，一律先挂断再回拨。
```

#### 脚本 2：快递理赔

```
骗子：您的快递丢了，我们双倍赔偿，请加微信办理，超时视为放弃。
正确反应：不加微信，打开购物 App 自己查物流。
训练点：正规理赔都在 App 里办，不会加私人微信。
```

#### 脚本 3：冒充公检法

```
骗子：我是XX市公安局的，您的账户涉嫌洗钱，需要配合调查，
      把钱转到安全账户自证清白，不许告诉任何人。
正确反应：挂断。打 110 核实（自己拨，不用对方给的号）。
训练点：公检法不会电话办案，没有「安全账户」，更不会让你别告诉家人。
```

#### 脚本 4：养老项目

```
骗子：阿姨，我们这个养老社区，交 20 万定金锁定名额，
      每年返 15%，还能优先入住，名额只剩 3 个了。
正确反应：不交钱，先查这家机构在民政部门有没有备案；
         把合同拿给子女看；不签任何当场催签的文件。
训练点：高回报 + 催你当场决定 = 有问题。真项目不怕你回去想三天。
```

#### 脚本 5：帮忙走账

```
骗子：阿姨，帮我个忙，我这边收款不方便，用您银行卡收一下，
      转给您 5% 手续费，钱到账您再转给我就行。
正确反应：拒绝。这不是帮忙，是帮人洗钱，卡会被冻结、人可能涉案。
训练点：任何「用你的卡收钱再转出去」都是跑分，不管对方是谁。
```

### 第四步：出事后处理

顺序不能错：**先止损失，再安抚，最后复盘。** 顺序错了，老人会瞒着你。

| 顺序 | 做什么 | 为什么 |
|---|---|---|
| 1 | 冻结账户、改密码、打 110 | 每多一分钟，可能多一笔转账 |
| 2 | 说一句「这不是你的错」 | 羞耻感会让老人闭嘴，闭嘴就更危险 |
| 3 | 陪他复盘「哪一步开始不对」 | 让他自己说出来，比你讲十遍有用 |
| 4 | 重新设置手机防线 | 骗子手里有他的信息，会来第二次 |
| 5 | 通知亲友，防止被冒充 | 骗子常拿通讯录二次行骗 |

## 沟通话术

### 三句开场，别说错

| 别说 | 改成 |
|---|---|
| 「你怎么这么傻」 | 「这不是你的错，他们专门研究你们这个年龄段」 |
| 「我早就说过」 | 「现在知道了也不晚，我们一起处理」 |
| 「以后别乱点」 | 「以后有这种事，你先发我看一眼，我帮你看」 |

### 四个有效的说法

**1. 用别人的故事，不用自己的道理**
「我同事他爸上个月就遇到一模一样的，被骗了 8 万」——比「这是骗局」有效十倍。人对自己的事防御，对别人的事好奇。

**2. 让父母当老师**
「妈，你帮我看看这个，我觉得像骗子，你怎么判断？」——角色反转，他会认真分析，而且记得住。

**3. 给一个具体的硬规则，不给一堆道理**
「以后只要有人让你转账，不管是谁，先给我打个电话。就这一条。」——老人记不住十条，能记住一条。

**4. 承认自己也不懂**
「这个我也拿不准，我们一起查查」——比「你不懂」更容易让他配合。

## 反模式

| 做法 | 为什么没用 |
|---|---|
| 一上来讲十个骗局案例 | 记不住，还会觉得你烦 |
| 把父母手机没收/断网 | 剥夺自主感，他会偷偷用 |
| 当着亲戚面说父母被骗 | 丢面子，以后有事绝不告诉你 |
| 只装 App 不教怎么用 | 装了等于没装 |
| 「你要是信他们就不管你了」 | 威胁只会让他更依赖骗子的「关心」 |
| 事后反复提这件事 | 羞耻感累积，下次瞒得更深 |
| 觉得「我妈精明，不会被骗」 | 骗子不挑智商，挑的是那一刻的需求 |
| 只防电话不防微信 | 现在七成骗局从微信开始 |

## 常见问题

**Q：父母不信我，信群里那个「老师」，怎么办？**
别直接否定那个人，会说「你懂什么」。换两个办法：一是让父母把收益截图给你看，你帮他算真实年化；二是找个他信的人（老同事、社区民警、银行柜员）一起说。第三方永远比子女有效。

**Q：老人被骗了，还替骗子说话，怎么办？**
这是「洗脑期」，讲道理没用。先做三件事：冻结账户（物理阻断）、联系警方、找老人信任的第三方介入。这个阶段最忌讳争吵，吵一次，他就再也不跟你说了。

**Q：给爸妈装了反诈 App，他们嫌麻烦卸载了。**
别硬装。改成「我帮你设置好，你不用管，有骚扰电话它自己拦」。把复杂动作变成零操作，老人才会留。

**Q：父母自己住，我不在身边，怎么防？**
三个远程动作：① 单日转账限额调到 5000 以下（这个最有效）；② 加一两个邻居/社区工作人员微信，请他们留意；③ 每周固定通话一次，聊生活不聊防骗，让他有事愿意跟你说。

**Q：要不要把父母的银行卡收过来？**
不建议一刀切。可以改成「大额需你陪同」——卡还在他手里，但单笔限额降低，超过额度需要你到场。既保留尊严，又控住风险。

**Q：老人被骗后抑郁了，怎么办？**
钱的事先放下，先处理情绪。明确告诉他「钱可以再挣，你比钱重要」。如果持续失眠、不愿出门超过两周，建议看心理科——被骗后的创伤反应是真实存在的。

## 错误处理

| 情况 | 处理 |
|---|---|
| 只说「我妈可能被骗了」 | 追问：多大年纪、自己住吗、在跟什么人聊、钱转了没 |
| 正在被骗、钱即将转出 | 跳过分析，直接给三步：打 110、冻结卡、联系银行 |
| 父母拒绝配合 | 改从「限额」入手，这个不需要老人同意也能办 |
| 老人有认知障碍 | 提示需要监护安排，建议咨询律师或社区 |
| 涉及具体养老机构 | 只给查询路径（民政部门备案），不下结论 |
| 子女情绪激动、想「教训」父母 | 先降温：说明对抗的后果，再给替代方案 |

## 稳定性与一致性

- 同一画像每次给的防线清单一致，不会这次九项下次五项
- 不联网，不查询具体机构、账户、号码
- 演练脚本固定五个，可反复使用
- 不评估父母的认知能力，只按你描述的情况给建议

## 能力边界

**能做**：易感类型判断、手机设置清单、演练脚本、沟通话术、事后处理流程。

**不能做**：
- 不追回资金、不联系平台、不代报警
- 不判断具体机构/平台是否合法
- 不替代医疗判断（认知障碍、抑郁需就医）
- 不提供任何诈骗实施方法

**一条底线**：防骗的关键不是让父母「变聪明」，而是让他在那一刻「有个理由先停下来」。这个理由，最好是你。
