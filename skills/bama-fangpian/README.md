# 爸妈防骗

不是给老人看的，是给子女用的。把防线装进父母手机，把反应练成肌肉记忆。

## 一分钟演示

**输入**

```
我爸 68，自己住，退休前是老师，爱看新闻也爱转发。
最近在一个群里跟着"老师"学炒股，已经投了 3000，说赚了 400。
```

**输出（节选）**

```
易感类型：贪利型 + 孤独型
- 贪利：退休金想增值，被"高收益"击中
- 孤独：群里有人天天叫老师、问早安，补上了陪伴

手机防线（先做这四项）
1. 单日转账限额调到 5000 以下  ← 最有效
2. 关闭未知来源安装
3. 微信关闭"手机号搜到我"
4. 装国家反诈中心，开来电预警

演练脚本 4（养老/投资）
骗子：投 3000 赚 400，老师带单，名额有限
正确反应：先试提现。提不出来 = 数字是假的

一句话规则
「爸，以后只要有人让你转钱，不管是谁，先给我打个电话。就这一条。」
```

## 它解决什么

| 痛点 | 现在 |
|---|---|
| 说了不听，越劝越僵 | 给「不吵架的四种说法」，用别人的故事代替讲道理 |
| 不知道从哪防起 | 九项手机设置，具体到点哪个按钮 |
| 讲案例记不住 | 五个演练脚本，你演骗子他演自己 |
| 出事后老人瞒着不说 | 三步顺序：先止损、再安抚、最后复盘 |
| 每个老人情况不同 | 先判四类易感画像，再给对应策略 |

## 怎么用

1. 说清父母情况：年龄、住哪、性格、有没有被骗过
2. 说目标：提前防 / 已发现苗头 / 出事后处理
3. 说要哪种输出：手机清单 / 演练脚本 / 话术

## 四类易感画像

| 类型 | 最容易被什么骗 | 对策重点 |
|---|---|---|
| 孤独型 | 假亲情、杀猪盘 | 补陪伴 + 识别"无条件对你好" |
| 贪利型 | 虚假投资、养老项目 | 用真实收益对比，不讲道德 |
| 权威恐惧型 | 冒充公检法、医保社保 | 建立"先打给我"的硬规则 |
| 热心型 | 刷单跑分、代收款 | 讲清"帮人可能犯法"的后果 |

## 适用与不适用

**适用**：子女给父母做防护、社区/银行做老年防骗宣传、老人被骗后的处理。

**不适用**：追回资金、判断机构合法性、认知障碍的医疗判断。

## 说明

- 手机设置路径以安卓/微信通用版本为准，不同品牌略有差异
- 不联网、不查询具体机构与账户
- 紧急情况直接拨 110 或 96110
- 不提供任何诈骗实施方法
