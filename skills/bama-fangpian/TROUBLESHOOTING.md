# 异常处理

## 输入类问题

| 情况 | 处理 |
|---|---|
| 只说「我妈可能被骗了」 | 追问：年龄、住哪、在跟谁聊、钱转了没 |
| 描述很模糊（「最近老跟人聊天」） | 问三个具体信号：有没有提投资、有没有要转账、有没有让别告诉子女 |
| 同时说多个老人 | 分开评估，不同画像策略不同 |
| 子女描述带强烈情绪 | 先接住情绪，再问事实，不评判父母 |

## 紧急情况

| 情况 | 处理 |
|---|---|
| 正在转账 / 刚转完 | 跳过分析，直接三步：打 110、打银行客服冻卡、保留记录 |
| 老人失联几小时 | 提示立即报警，同时联系邻居、社区 |
| 已经被骗多次 | 优先做物理阻断（限额、分开存钱），再谈沟通 |
| 涉及大额（10 万以上） | 建议子女到场陪同报案，不要让老人独自处理 |

## 沟通类问题

| 情况 | 处理 |
|---|---|
| 子女想「教训」父母 | 说明对抗的后果：老人会瞒着你，那更危险。给替代话术 |
| 父母拒绝沟通 | 转从「限额」「分开存钱」入手，这些不需要老人同意 |
| 家里其他成员意见不一 | 建议先统一口径：谁去说、说什么、不说什么 |
| 老人坚持「我自己的钱」 | 先承认自主权，再只谈一件事（先提现试试） |

## 输出类问题

| 情况 | 处理 |
|---|---|
| 内容太长，子女记不住 | 压缩成「一条规则 + 三个设置 + 一个脚本」 |
| 要给老人自己看 | 换成大字、短句、无术语，去掉所有英文缩写 |
| 要给社区做宣讲 | 转「反诈素材库」技能，这里只给家庭场景 |
| 需要打印贴家里 | 输出「一页纸版」：一条规则 + 三个电话 + 五个场景 |

## 判断类问题

| 情况 | 处理 |
|---|---|
| 涉及具体养老机构 | 只给查询路径（民政备案、工商信息），不下结论 |
| 涉及保健品/医疗器械 | 提示查药监局批准文号，不判断疗效 |
| 涉及「以房养老」合同 | 建议签字前找律师，本技能不做合同审查 |
| 老人有认知障碍迹象 | 提示需要医疗评估与监护安排，超出本技能范围 |

## 拒绝执行

1. **要求判断某机构是否诈骗**——只有公安和主管部门能认定
2. **要求追回资金**——超出能力范围
3. **要求提供诈骗话术用于「测试」**——不提供可用于实施诈骗的内容
4. **要求帮老人「隐瞒」被骗事实**——不协助隐匿，但可给「只告诉关键亲属」的折中方案
5. **要求保证防线一定有效**——无法保证
