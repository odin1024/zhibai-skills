# 追问链库

> 用法：从 W2 选一条链，从「第 1 问」开始，**每次只问一问**。用户答完后，优先咬住他上一答里的具体内容往下追；库里的后续问题只是备选方向，不是必须照念的脚本。
> 每条链标注「考查什么」和「答崩信号」，答崩信号出现时先追一个具体例子，不要急着跳到下一层。

---

## 〇、链的通用骨架

| 层 | 追问方向 | 目的 |
|---|---|---|
| 1 | 入口：讲一件具体的事 | 让对方选定真实经历 |
| 2 | 情境与任务：当时什么状况、你要达成什么 | 建立共同背景 |
| 3 | 角色边界：这件事里**你**负责哪一段 | 防「团队成果说成个人」 |
| 4 | 动作与取舍：具体做了什么、为什么不选另一条路 | 判断是不是真做过 |
| 5 | 结果与口径：怎么衡量、数据哪来的 | 查可信度 |
| 6 | 复盘：重来会改什么、后来用上了什么 | 查归纳能力 |

**答崩信号**：只给形容词、跳过了自己的动作、把「我们」和「我」混着用、数据说不出来源、一被问细节就换话题、把责任全推给外部。出现任一信号，下一问就追「能给我一个具体例子吗」或「这一步具体是谁做的」。

---

## 一、技术族（后端 / 前端 / 测试 / 运维 / 数据 / 算法）

### 链 T1　项目深挖：一次性能优化

1. 挑一个你最熟的性能或稳定性问题，讲讲当时是什么状态。
2. 「慢」是按哪个接口、什么并发、什么时间段测出来的？
3. 这个数是谁给的、你怎么确认它可信？
4. 你负责的是哪一段，哪些部分不是你做的？
5. 当时考虑过哪些方案，最后为什么选这个、没选那个？
6. 上线后怎么验证，有没有回退预案？重来一次会改哪里？

**考查**：指标口径、方案取舍、边界诚实度、验证意识。
**答崩信号**：说不出测量条件、把「加了个缓存」当成全部方案、讲不出被否掉的方案。

### 链 T2　故障与协作：一次线上问题

1. 讲一次你参与处理线上问题的经过。
2. 最早是谁发现、你怎么被卷进来的？
3. 定位过程中你做的第一个动作是什么，为什么是它？
4. 有没有走过弯路，哪一步判断错了？
5. 当时和谁配合，信息是怎么同步的？
6. 事后沉淀了什么，后来真的用上了吗？

**考查**：过程真实性、归因诚实、协作方式、复盘是否落地。
**答崩信号**：全程「我们」、没有走过任何弯路、事后措施只写「加强监控」。

## 二、产品族

### 链 P1　需求判断：一个没做的功能

1. 讲一个你判断「先不做」的需求。
2. 这个需求是谁提的，他真正想解决什么？
3. 你用什么信息判断它优先级不高？
4. 反对意见是什么，你怎么回应的？
5. 后来这个判断被验证了吗，有没有反转？
6. 如果重来，你会不会改决定，为什么？

**考查**：需求归因、取舍依据、面对反对意见、是否承认判断失误。
**答崩信号**：把「排期不够」当成唯一理由、说不出反对意见、从不承认判断错。

### 链 P2　数据驱动：一次效果不达预期

1. 讲一个上线后效果没达到预期的版本。
2. 「没达到」是跟哪个目标比的，目标怎么定的？
3. 你拆了哪些数据去找原因？
4. 找到的原因里，哪个是你事先没想到的？
5. 之后做了什么调整，调整后怎么判定的？
6. 这件事改变了你后面做需求的方式吗？

**考查**：指标定义、归因逻辑、从失败里学到什么。
**答崩信号**：只有「用户不买账」没有拆解、把原因全归给运营或研发。

---

## 三、运营 / 增长族

### 链 O1　活动复盘：一次召回或拉新

1. 讲一次你负责的活动，先说目标是什么。
2. 目标人群怎么划分的，为什么这么分？
3. 你具体做了哪几件事，哪一件是你定的？
4. 结果数据是多少，口径和来源是什么？
5. 有没有哪一组效果明显差，你当时怎么解释？
6. 如果预算砍一半，你会保留哪部分？

**考查**：分群逻辑、动作具体度、数据口径、成本意识。
**答崩信号**：「效果很好」无数字、说不清对照组、把平台流量算成自己的功劳。

### 链 O2　内容 / 用户：一次负面反馈

1. 讲一次用户明确表达不满的经历。
2. 对方原话大概是什么，你第一反应做了什么？
3. 你怎么判断是个案还是普遍问题？
4. 有没有改产品/流程，还是只做了安抚？
5. 后来这类反馈还出现过吗？

**考查**：共情与事实区分、是否只做表面处理、闭环意识。
**答崩信号**：把用户描述成「不理解」、只有话术没有改动。

## 四、销售 / 商务族

### 链 S1　丢单复盘

1. 讲一个你很想拿下但最后没成的单子。
2. 最早接触的是谁，真正拍板的是谁？
3. 中间哪个节点你判断错了？
4. 竞对做了什么你当时没做到？
5. 这件事之后你改了哪个具体动作？

**考查**：决策链识别、诚实归因、可迁移的改进。
**答崩信号**：全怪价格或客户、说不出决策链、没有具体动作改进。

### 链 S2　长周期跟进

1. 讲一个跟进最久的客户。
2. 中间有没有过「快断了」的时候，你怎么续上的？
3. 每次联系给对方提供了什么，而不是单纯催？
4. 你怎么判断该继续投入还是放弃？

**考查**：过程耐心、价值提供、止损判断。
**答崩信号**：把「经常吃饭」当成方法、没有放弃标准。

## 五、职能族（财务 / 人力 / 行政 / 法务 / 采购）

### 链 F1　流程改动

1. 讲一次你推动流程或制度调整的经历。
2. 原来流程卡在哪一步，谁受影响最大？
3. 反对声音来自哪里，具体担心什么？
4. 你做了什么让对方愿意配合？
5. 上线后怎么确认它真的被用起来了？
6. 有没有出现过新问题，怎么补的？

**考查**：利益相关方识别、推动方式、落地验证。
**答崩信号**：只说「发了通知」、没有反对声音、不验证是否真被使用。

### 链 F2　差错处理

1. 讲一次你发现自己或流程出了错。
2. 什么时候发现的，第一件事做了什么？
3. 有没有向上同步，怎么说的？
4. 影响范围怎么控制住的？
5. 后来加了什么检查点？

**考查**：诚实、上报意识、控制影响、制度沉淀。
**答崩信号**：试图淡化影响、说「后来没再犯」却讲不出加了什么检查。

## 六、管理族（团队负责人 / 晋升答辩）

### 链 M1　人的问题

1. 讲一次你处理团队里比较棘手的人的问题。
2. 你最早观察到什么信号，隔了多久才介入？
3. 谈话前你准备了什么，谈话里哪句最难说？
4. 结果没有按预期走时，你换了什么做法？
5. 这件事对你后来的管理方式有什么影响？

**考查**：介入时机、沟通准备、面对不如意结果、管理反思。
**答崩信号**：把人标签化、只有「最后优化了」、不谈自己的责任。

### 链 M2　资源取舍

1. 讲一次人手或预算不够、必须砍掉一件事的时候。
2. 当时有几条线在抢资源，各自的价值怎么比？
3. 你砍掉的是哪一件，谁不同意？
4. 你怎么向团队解释这个决定？
5. 事后看这个取舍对不对，依据是什么？

**考查**：取舍标准、沟通透明、事后评估。
**答崩信号**：只说「按优先级」却讲不出标准、回避谁的利益受损。

## 七、应届 / 转行族

### 链 E1　可迁移能力

1. 讲一件你在学校 / 社团 / 上一行业里做成的事。
2. 这件事里你负责的是哪一段？
3. 遇到过最大的阻力是什么，你怎么绕过去的？
4. 有没有一个具体产出可以给我看（文档、活动、代码、报表）？
5. 这段经历里，哪一点能用在你要投的岗位上？

**考查**：事实具体度、能否把旧经验翻译到新岗位、产出意识。
**答崩信号**：只讲「锻炼了能力」、没有产出物、说不出和目标岗位的连接。

### 链 E2　学习过程

1. 讲一次你在短时间内学会一个陌生东西的经历。
2. 你第一周具体做了什么，怎么判断自己学偏了？
3. 卡最久的是哪一点，怎么解决的？
4. 有没有找人请教，问了什么问题？
5. 现在回头看，你会怎么学得更快？

**考查**：学习方法、求助能力、元认知。
**答崩信号**：只说「看了很多资料」、没有卡点、从不请教。

## 八、压力 / 陷阱题链（跨岗位通用）

| 入口 | 追问方向（逐层，一次一问） | 守住的边界 |
|---|---|---|
| 为什么离职 | 「具体是哪一类安排让你决定走」→「你当时试过什么办法」→「新岗位也有类似情况你会怎么处理」 | 事实照说、不评价具体的人、落到自己想要什么 |
| 空窗期 | 「这段时间主要在做哪几件事」→「其中哪一件和你现在投的岗位有关」→「为什么现在准备好了」 | 不编经历、不掩盖，讲清节奏与准备 |
| 你的缺点 | 「能给我一个具体场景吗」→「这个缺点带来过什么后果」→「现在有什么具体做法在补」 | 不拿优点伪装成缺点、给真实改进动作 |
| 期望薪资 | 「你的预期是按什么算出来的」→「除了 base 你还看什么」→「如果结构不同你怎么比」 | 不替用户报数、不代做决策，只练表达结构 |
| 和面试官意见不同 | 「你当时依据什么判断」→「有没有可能对方是对的」→「你会怎么把分歧摆到台面上」 | 不逞强、不盲从，讲清依据与沟通方式 |

**压力链的评分重点**：可信度、边界感、表达稳定性。不追求「漂亮话」，追求「不塌、不编、不攻击他人」。

---

## 九、使用纪律

- 库里的问题是**备选方向**，不是脚本。用户答里出现了更有价值的细节，就追那个细节。
- 不把多层问题合并成一次输出；「一问」可以是同一追问点的两个侧面，但不能是两个互不相关的方向。
- 不问公司名、客户名、真实姓名、具体薪酬数字。
- 用户答不上来，给一个提示角度；连续两轮答不上来，换更基础的链并记进复盘。
- 这些是通用模拟，**不代表任何真实公司的面试流程或题库**。
