# 模拟面试追问教练

不给你一屏题库。像真实面试那样，**每次只问一个问题**，顺着你的回答一层层往下追。

专治三件事：背了一堆题一被追问就卡住、答完不知道哪里好哪里差、项目经历讲不清自己到底做了什么。

---

## 一分钟上手

```
用 interview-mock-chain 陪我练面试。
【目标岗位】后端开发，JD 要点：高并发、跨团队协作
【想练】项目深挖
【我的经历】做过一个订单系统优化，主要改了查询
【可选】面试轮次：二面 / 用过简历诊断，最弱项是「成果量化」
```

Agent 会先给一张建档卡（岗位核心能力 / 高危追问点 / 本轮目标），确认后开始第 1 问。

**你答一句，它追一句。** 每一答都会给四维评分和指回原话的证据。想停随时说「停」，立刻给复盘。

---

## 会得到什么

| 阶段 | 交付物 |
|---|---|
| 建档 | 岗位核心能力、高危追问点、本轮只练一件事 |
| 选链 | 行为 / 项目深挖 / 压力陷阱三类链，按七个岗位族选细节 |
| 陪练 | 一问一追，带 `[第 2/5 问 · 项目深挖 · 正在追：方案取舍]` 进度标记 |
| 评分 | 事实密度 / 结构 / 岗位关联 / 可信度，每项 0–3 分 + 具体证据 |
| 复盘 | 完整问题链、逐答诊断表、STAR 改写对照、下一轮重点（1–2 条）、简历联动项 |

### 一轮长什么样

```
[第 2/5 问 · 项目深挖 · 正在追：方案取舍]
你提到「最后选了方案 B」。当时被否掉的方案 A，最主要的顾虑是什么？
是你一个人定的，还是有人提出过不同意见？
```

```
【第 2 答评分】事实密度 2/3 · 结构 1/3 · 岗位关联 2/3 · 可信度 3/3
- 加分证据：「我先把三个部门的排期拉到一张表上」——有具体动作 ✅
- 扣分证据：讲了 4 句背景才进入自己的动作，结构偏散 ⚠️
- 这一答最该改的一处：把「后来协调好了」换成具体是怎么协调的
```

---

## 它不做什么

- **不编经历、不造数字。** 没数据就给「怎么表述」和「面试前核对什么」，不会把「效果不错」改成「提升 37%」。
- **不发题库、不冒充。** 不声称代表任何公司，不编所谓内部面试题。
- **不替你做决定。** 薪资、offer、要不要离职，只练表达。
- **不承诺结果。** 不预测录用概率，评分只针对「这一答」，不评判人。

> 底线：宁可让你承认「这个数我记不清」，也不帮你造一个能背出来的数字。

## 配套文件

- `SKILL.md` — 五步工作流、输出模板、三个真实示例、硬规则、反模式
- `references/追问链库.md` — 七个岗位族 14 条链 + 压力题链，含考查点与答崩信号
- `references/STAR改写库.md` — 10 组改写对照、没有数据怎么办、把「我们」改成「我」
- `scripts/verify.py` — 技能包自检

```bash
cd interview-mock-chain && python scripts/verify.py
```

## 与简历诊断联动

若用过 `resume-checkup`（简历诊断医生）：把六维评分里最弱的一项定为本轮目标，把「面试官预判问题」直接当链的入口，练完再看改过的简历表述能不能经得住三层追问。反过来，复盘里发现的「角色写模糊」「数字没出处」应回简历里修正，而不是只在口头上补。
