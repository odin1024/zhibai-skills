# 测试项库

按设备/系统类型给出可复用的测试项。**指标值是行业常见区间，只作参考**——实际以招标文件条款和产品标称值为准，本文件不用来替代招标要求。

用法：找到对应设备类型 → 挑测试项 → 按「六要素」补全步骤与判定准则。

---

## 九、性能测试参数对照表

写性能项时，这五项缺一不可：

| 参数 | 常见取值 | 说明 |
|---|---|---|
| 包长 | 64 / 512 / 1518 字节 | 小包测转发能力，大包测吞吐 |
| 测试时长 | 60s / 300s / 24h | 短时测峰值，长时测稳定 |
| 并发模型 | 长连接 / 短连接 / 混合 | 决定测的是并发数还是新建速率 |
| 测试工具 | RFC2544 打流仪 / JMeter / Locust | 写明型号与版本 |
| 取值口径 | 平均值 / 峰值 / P95 | 不同口径结果差异大 |

## 十、判定准则写作模板

不合格：「性能良好」「功能正常」「安全可靠」。

合格模板：

```
在【测试条件】下，【观测指标】达到【阈值】，且【附加约束】。
```

示例：
> 在 1518 字节包长、RFC2544 双向打流、持续 60s 的条件下，整机吞吐 ≥ 10Gbps，丢包率 ≤ 0.001%，且 CPU 占用 ≤ 80%。

## 十一、常见缺陷分级参考

| 等级 | 定义 | 处理时限 |
|---|---|---|
| P0 阻断 | 核心功能不可用、数据丢失、安全事故 | 立即修复，修复前不验收 |
| P1 严重 | 主要功能异常、性能不达标 | 3 个工作日内 |
| P2 一般 | 非核心功能异常、体验问题 | 10 个工作日内 |
| P3 建议 | 优化项、文案问题 | 可延至下个版本 |
