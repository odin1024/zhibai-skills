## 一分钟看懂

把可疑的东西贴进来，四件事一次说清：

```
输入：一段短信 / 聊天记录 / 链接 / App 截图 / 电话内容转述
  ↓
① 这是不是骗局 —— 高 / 中 / 低 / 信息不足
② 骗子走到哪一步 —— 接触 / 建信 / 诱导 / 转账 / 收割
③ 现在该做什么 —— 止损五步，按顺序
④ 怎么跟家人说 —— 直接可念的话术
```

不判法律、不追钱、不代报警。只做一件事：**在你按下转账之前，把话说清楚。**

---

## 什么时候用

| 场景 | 你会怎么说 |
|---|---|
| 收到奇怪短信/链接 | 「这个说我快递丢了要理赔，是真的吗」 |
| 家人转发来一段话 | 「我妈说群里有人带她炒股，你看看」 |
| 网恋/交友对象提投资 | 「聊了两个月，他让我跟他一起买币」 |
| 有人自称公检法/客服/领导 | 「说我涉嫌洗钱，要我把钱转到安全账户」 |
| 招聘/兼职机会 | 「日结 300，只要帮忙拍店铺照片，靠谱吗」 |
| 已经转了钱 | 「我刚转了 2 万，还有救吗」 |

## 什么时候不该用

- **要追回资金**→ 只能报警（110 / 96110），本技能给不了追款承诺
- **要判断某个平台是否合法持牌**→ 去证监会、银保监会官网查，本技能只做风险提示
- **要法律定性或起诉**→ 需要律师
- **要举报某个账号**→ 走平台举报 + 国家反诈中心 App，本技能给流程不给结果
- **已经转了很久、金额巨大**→ 立刻打 110，不要先看分析

## 三步上手

**第一步**：把可疑内容原样贴进来（截图也行，能读图就直接给图）

**第二步**：补三句背景——谁发来的、你和对方什么关系、钱转了没有

**第三步**：如果已经被骗，第一句就说「已经转了 X 元」，止损动作会排在最前面

## 核心工作流

### 第一步：抽要素

不管什么形式，先抽出六个要素：

| 要素 | 为什么要 |
|---|---|
| 谁在联系你 | 陌生人 / 自称机构 / 熟人 / 网恋对象——决定套路类型 |
| 通过什么渠道 | 短信 / 微信 / QQ / 电话 / 陌生 App / 邮件 |
| 要你做什么 | 转账 / 点链接 / 下载 App / 屏幕共享 / 提供验证码 / 帮忙收款 |
| 给什么好处或施加什么压力 | 高收益 / 退款 / 涉案 / 限时 / 情感绑定 |
| 收款方是谁 | 个人卡 / 对公账户 / 虚拟币地址 / 陌生平台 |
| 时间压力 | 催得多急——越急越可疑 |

六要素里只要出现「陌生渠道 + 要钱/要码/要装 App + 催得急」，基本可以定性。

### 第二步：匹配骗局类型

18 类高频骗局，按「要你做什么」归类，比按名字记更好用：

> 每一类的完整拆解（骗子原话、关键转折点、常见变种、止损动作、易感人群）见 `references/18类骗局详解.md`。判断拿不准时先查那份。

| 他要你做 | 大概率是 | 关键识别点 |
|---|---|---|
| 垫钱做任务、刷单、点赞返佣 | 刷单返利 | 先给小利，后面要你垫大额 |
| 下载 App 投资、买币、炒股带单 | 虚假投资 / 杀猪盘 | 平台数据可后台改，提现要「缴税」 |
| 转到「安全账户」自证清白 | 冒充公检法 | 公检法从不会电话办案、更不会要转账 |
| 点链接填银行卡、退赔款 | 冒充客服退款 | 官方退款原路返回，不要你填卡号 |
| 加微信/QQ 后让你帮忙转账 | 冒充领导熟人 | 头像对、语气不对，一定电话核实 |
| 交保证金才能放款 | 虚假贷款 | 正规贷款放款前不收任何费用 |
| 私下交易游戏账号装备 | 游戏交易 | 脱离平台担保 = 无保障 |
| 买保健品、养老床位、以房养老 | 养老诈骗 | 高回报 + 情感关怀 + 催签合同 |
| 视频里看到熟人找你借钱 | AI 换脸 | 让他用手挡脸、转头，或直接挂断回拨 |
| 声音像亲人说出事了要钱 | 语音克隆 | 问只有你们知道的事 |
| 让你开屏幕共享「指导操作」 | 屏幕共享 | 共享 = 他能看到你的验证码 |
| 帮你代收货款、走账、买币 | 洗钱跑分 | 你的卡会涉案被冻结 |
| 高薪兼职、拍店铺照、代下单 | 招聘诈骗 | 先交押金/培训费/服装费 |
| 网恋后带你投资 | 杀猪盘 | 感情升温越快，越可能是剧本 |
| 中奖、退税、补贴要你先交钱 | 中奖诈骗 | 真中奖不会让你先付钱 |
| 冒充房东/中介收租、看房押金 | 租房诈骗 | 不见房不交钱 |
| 冒充学校/老师收资料费 | 冒充老师 | 群里发收款码，先电话核实 |
| 让你下载「官方」App 装证书 | 木马/远控 | 非应用商店来源一律不装 |

### 第三步：判断阶段

骗子有固定的推进节奏，判断阶段才知道该做什么：

| 阶段 | 典型信号 | 你还有多少余地 |
|---|---|---|
| 1 接触 | 陌生添加、群发短信、陌生电话 | 最大，直接不理 |
| 2 建信 | 给小额返利、发证件照、视频通话、晒收益 | 大，停止互动即可 |
| 3 诱导 | 让你下载 App、注册平台、小额试水 | 中，钱还没出去 |
| 4 转账 | 加大投入、催你补单、要保证金 | 小，立刻停手 |
| 5 收割 | 提现失败、要缴税、要解冻费、失联 | 极小，只能报警 |

**已经在第 4、5 阶段，止损动作优先于一切分析。**

### 第四步：风险定级

只给四档，不给模糊结论：

- **高**：命中 2 个以上硬信号（陌生渠道要钱、要验证码、要装非官方 App、要屏幕共享、催转账）
- **中**：有可疑点但缺关键证据（如对方身份无法核实、平台查不到资质）
- **低**：能核实到官方渠道且无资金要求（仍建议二次核实）
- **信息不足**：缺关键要素，需要补充（明确列出还缺什么）

### 第五步：给止损动作

按「钱有没有出去」分两条路：

**钱还没转**

1. 停：不再回复，不点链接，不装 App
2. 断：挂断/拉黑/退群
3. 查：官方 App 或官网自行核实（不要用对方给的电话和链接）
4. 告：告诉一个家人，别一个人扛
5. 装：国家反诈中心 App，开启来电预警

**钱已经转了**

1. **立刻打 110**（比任何分析都重要），说明转账时间、金额、对方账户
2. 打银行客服冻结/挂失涉案卡（工行 95588、建行 95533、农行 95599、中行 95566、招行 95555）
3. 保留全部证据：聊天记录、转账凭证、对方账号、通话记录、App 名称
4. 改密码：银行卡、支付、社交账号（尤其给过验证码的）
5. 告知家人，防止被二次诈骗（「帮你追款」的也是骗子）

**永远不要做**：找「网络追款」「黑客追回」——这是二次诈骗，专骗已经被骗的人。

## 技术检测维度

除了话术，这几项能直接看出问题：

| 检查项 | 怎么看 | 危险信号 |
|---|---|---|
| 链接域名 | 看主域名，不看前缀 | `icbc-tmall.xyz`、`95588.cn.com`、乱码域名 |
| 短链接 | 展开后再看 | 不敢给你看真实地址 |
| 电话号码 | 95 开头也可能是改号 | 回拨打不通、转人工要你加微信 |
| App 来源 | 只认应用商店 | 发 apk 安装包、要装「证书」、要开无障碍权限 |
| 收款账户 | 个人卡 vs 对公 | 正规机构不会让你转个人卡 |
| 虚拟币地址 | 一旦转出无法撤回 | 让你买 USDT 充值 |
| 屏幕共享 | 任何理由都不能开 | 开了等于把验证码给对方看 |

## 三个真实样例

### 样例 1：快递理赔

**输入**
> 「【XX快递】您的包裹在运输中丢失，请添加客服微信 138xxxx 办理理赔，超时视为放弃。」

**输出**

判断：**高危**｜类型：冒充客服退款｜阶段：第 2 阶段（建信）

为什么：
1. 正规快递理赔在官方 App 或小程序内办理，不会让你加私人微信
2. 「超时视为放弃」是制造紧迫感
3. 加了微信后，下一步一定是让你填银行卡或扫码退款

现在做：不添加，去官方 App 查物流；已添加的，删除并拉黑。

### 样例 2：网恋带投资

**输入**
> 「我们聊了一个多月，他说他叔叔在交易所内部，跟着买稳赚。他让我先投 5000 试试，昨天账户显示赚了 800。」

**输出**

判断：**高危**｜类型：杀猪盘（虚假投资）｜阶段：第 3 阶段（小额试水）

为什么：
1. 「内部消息 + 稳赚」是投资诈骗的标准开场
2. 账户里的 800 是平台后台数字，不是真钱，目的是让你加码
3. 一个多月的情感铺垫是剧本，不是巧合
4. 下一步会是：加大投入 → 提现失败 → 要你缴税/保证金

现在做：一分钱都不要再投；试着提现那 5000（大概率提不出）；保留全部聊天和转账记录；打 110 或 96110 咨询。

**关键提醒**：这类骗局受害者最难受的不是钱，是「感情也是假的」。跟家人说的时候，先别提钱，先陪着。

### 样例 3：冒充公检法

**输入**
> 「我是XX市公安局的，你的银行卡涉嫌洗钱，现在需要你配合调查，把钱转到安全账户自证清白。不许告诉任何人，否则按包庇处理。」

**输出**

判断：**高危**｜类型：冒充公检法｜阶段：第 4 阶段（即将转账）

为什么：
1. 公检法**永远不会**电话办案，也不会设「安全账户」
2. 「不许告诉别人」是切断你求助渠道的标准手法
3. 真涉案会是书面通知 + 本人到案，不会让你转账

现在做：立刻挂断；不要转任何钱；打 110 核实（用自己拨的号码，不用对方给的）；如果已经转了，马上报警 + 冻卡。

## 反模式

| 做法 | 为什么危险 |
|---|---|
| 「我先投一点试试」 | 小额返利是诱饵，试了就进套 |
| 「我跟他视频过，是真的」 | AI 换脸 30 秒就能做，视频不等于本人 |
| 「他说可以提现，我提了 200 成功了」 | 前期小额提现是设计好的，为了让你信 |
| 「我不告诉他银行卡，只给验证码」 | 验证码等于密码，给了就等于开门 |
| 「我就点开看看，不填信息」 | 有些链接点开就中招，或跳转到仿冒页 |
| 「他说自己是警察，还发了证件照」 | 证件照可 PS，警号可伪造，回拨 110 才准 |
| 「我自己能搞定，不告诉家人」 | 孤身一人最容易被话术带走 |
| 被骗后找「网络追款」 | 二次诈骗，专骗已经慌了的受害者 |
| 觉得「我这么聪明不会被骗」 | 骗子不挑智商，挑的是「那一刻你正好需要」 |

## 常见问题

**Q：对方能说出我的姓名、订单号、身份证号，是不是真的？**
不是。这些信息在黑产里几毛钱一条，泄露渠道很多。能说出你的信息，恰恰说明信息被卖了，不是官方证明。

**Q：视频里明明是我朋友/儿子，怎么可能是假的？**
AI 换脸 + 语音克隆现在成本极低，几段公开视频就够。判断方法：让他用手在脸前晃一下（换脸会糊）、突然问他只有你们知道的事、或者直接挂断用原号码回拨。

**Q：我已经转了钱，还有希望追回吗？**
越早报警越好。转账后短时间内（通常以分钟计）资金可能还在中间环节，警方和银行有止付机会，过了这个窗口就只能走冻结和追缴流程。但要有心理准备：追回比例不高。这时候最重要的是别再被「追款服务」骗第二次。

**Q：怎么跟爸妈说他们才听？**
别说「你怎么这么傻」。说三句：这不是你的错，现在骗子专门研究你们这个年龄；我帮你处理，你不用管；以后有事先发我，我帮你看。对抗情绪只会让他们瞒着你。

**Q：96110 是什么电话？**
全国反诈专线。接到 96110 来电，说明你可能正在被骗，一定要接。主动咨询也可以打。

**Q：装国家反诈中心 App 有用吗？**
有用，主要价值是来电预警和 App 自检。但别指望它拦下所有骗局，最终还是要靠「不转账、不给码、不共享屏幕」这三条。

## 错误处理

| 情况 | 处理 |
|---|---|
| 只给一句「是不是骗子」 | 追问：谁发的、说了什么、要你做什么、钱转了没 |
| 截图看不清 | 请对方把文字复制出来，或分块截图 |
| 信息涉及具体银行账户 | 只做风险提示，不查询、不核实账户真伪 |
| 用户情绪激动、已经转了大额 | 先给止损三步（报警/冻卡/留证），分析放后面 |
| 用户坚持「这就是真的」 | 不争论，列出三条可自行核实的动作，让他自己去验 |
| 要求判断某平台是否合法 | 给查询路径（证监会/银保监/国家企业信用信息公示系统），不下结论 |

---

## 稳定性与一致性

- 同类信息每次判断结论一致，不会这次高危下次低危
- 不联网查库，判断基于你提供的内容 + 通用骗局特征
- 不做金额估算、不承诺追回比例
- 长对话中会记住前面说过的要素，不重复追问

## 能力边界

**能做**：判断是否疑似骗局、识别类型、判断阶段、给止损动作、给沟通话术、做技术维度提示。

**不能做**：
- 不追回资金、不联系平台、不代报警
- 不做法律定性（是否构成犯罪由司法机关认定）
- 不核实具体账户、号码、平台的真伪（那需要官方渠道）
- 不提供任何诈骗实施方法，也不做「反推骗子手法」的教学

**一条底线**：所有判断都是「疑似」，最终以公安机关认定为准。但只要出现「陌生渠道 + 要钱 + 催得急」，先停手，再分析。
