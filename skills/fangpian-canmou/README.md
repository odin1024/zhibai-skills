# 防骗参谋

贴来可疑信息，30 秒判断是不是骗局，拆出骗子走到哪一步，给止损动作和家人沟通话术。

## 一分钟演示

**输入**

```
我妈今天收到一条：「【XX快递】您的包裹丢失，请添加客服微信 138xxxx 办理理赔，超时视为放弃。」
她已经加了，对方让她下载一个 App 填银行卡。她还没填。
```

**输出**

```
判断：高危　类型：冒充客服退款　阶段：第 3 阶段（诱导下载 App）

为什么是骗局
1. 正规理赔在官方 App 内办理，不会加私人微信
2. 让你装的 App 不在应用商店
3. 「超时视为放弃」是制造紧迫感

现在就做
1. 不要下载、不要填卡号
2. 退出群、拉黑
3. 打开购物 App 官方客服核实
4. 卸载已装的来路不明 App，改一次支付密码

跟妈妈怎么说
「妈，这个我查过了，是骗子。他们让你下的那个 App 会偷你银行卡信息。
 你没填就对了，这一步你做得对。以后有这种事你先发我看看，
 现在这种骗局专门骗细心人。」
```

## 它解决什么

| 痛点 | 现在 |
|---|---|
| 收到可疑信息，不知道信不信 | 四档判定：高/中/低/信息不足 |
| 光说「是骗子」没用，不知道下一步 | 止损五步，按钱有没有出去分两条路 |
| 骗子能报出你的姓名订单号，看着很真 | 拆穿信息泄露不等于官方 |
| 劝爸妈别信，反而吵架 | 给可直接念的话术，不对抗 |
| 视频里明明是熟人 | 教三个当场验真的动作 |

## 怎么用

1. 把可疑内容原样贴进来（截图也行）
2. 补三句：谁发的、你们什么关系、钱转了没
3. 如果已经转了钱，第一句就说金额和时间

## 覆盖范围

18 类高频骗局：刷单返利、虚假投资理财、杀猪盘、冒充公检法、冒充客服退款、冒充领导熟人、虚假贷款、游戏交易、养老诈骗、AI 换脸、语音克隆、屏幕共享、虚拟货币洗钱、招聘诈骗、中奖退税、租房诈骗、冒充老师、木马远控。

技术检测维度：域名、短链、号码、App 来源、收款账户、虚拟币地址、屏幕共享。

## 适用与不适用

**适用**：任何收到可疑信息、拿不准要不要转账、想劝家人但不知道怎么开口的场景。

**不适用**：追回资金、法律定性、核实平台资质、代报警。

## 说明

- 判断基于通用骗局特征与你提供的信息，不联网查库
- 所有结论都是「疑似」，最终以公安机关认定为准
- 紧急情况请直接拨 110 或反诈专线 96110
- 不提供任何诈骗实施方法
